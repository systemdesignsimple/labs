A browser can keep a copy of a response so it does not have to ask the server again. The Cache-Control header tells the browser how long that copy stays fresh. With max-age set to 3600, the copy is treated as fresh for one hour. After that time the browser must check with the server before it uses the stored copy again. If the server's answer has not changed, it can reply with status 304 and send no body. This saves bandwidth because the client reuses the bytes it already has.
