A load balancer sends traffic only to servers it believes are healthy. It checks each server by calling a health endpoint every 5 seconds. If a server fails 3 checks in a row, the load balancer stops sending it new requests. The server is added back after it passes 2 checks in a row. A health check that only returns OK without testing the database can hide real failures. A check that tests too much can mark every server down at the same time.
